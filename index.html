配置部分

  • 把插件解压到 naviteplugins 下面，如图添加插件配置；
  • 开启麦克风权限；

代码部分

第一步
  • 在uni项目启动的地方比如 onLaunch 时，添加
// 引入包
var testModule = uni.requireNativePlugin("HollyOC-HollyOC")

// 初始化 参数
testModule.iAccount({
					account: "xxxx",
					chatid: 'xxxx-xxxx-xxxx',
					param: {
						"a":"aaa",
					}
				})
第二步
  • 新建 nvue 页面(比如：/pages/index/test/test), 在新建的 nvue 页面添加组件：
<dc-testmap style="width:100%;min-width: 333px;height:400px"></dc-testmap>
  • 在需要的地方跳转到 nvue 页面；
uni.navigateTo({
	url:'/pages/index/test/test'
});
